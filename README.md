# Wamiri — Tailoring Booking Website

Wamiri is a responsive client-facing tailoring website built with **React, TypeScript, Tailwind CSS and Vite**. It provides a simple booking experience that allows customers to enter their details and continue the booking process through WhatsApp.

## Live Demo

https://wamiri-frontend.vercel.app

## Features

- Responsive interface for mobile and desktop
- Tailoring booking form
- Controlled form inputs using React state
- Form validation and error handling
- WhatsApp-based booking workflow
- Reusable React components
- TypeScript for safer component and form logic
- Tailwind CSS for responsive styling

## Booking Flow

1. A customer enters their booking information in the form.
2. React state keeps the form fields synchronized with the interface.
3. The submitted information is formatted into a booking message.
4. The customer continues to WhatsApp to send the booking details to the business.
